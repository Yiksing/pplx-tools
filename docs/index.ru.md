# Perplexity CLI toolkit

<p class="homepage-scope-note" role="note">
  <strong>НЕ для API с оплатой по мере использования</strong>
</p>

Perplexity инструментарий для архивирования разговоров и интерактивных запросов (`pplx-export` / `pplx-ask`).

Он напрямую общается с REST/GraphQL API Perplexity, используя файлы cookie вашего браузера для входа в систему, и архивирует разговоры — шаги, цитаты, отчеты глубокого исследования, ресурсы компьютерного режима и рабочие процессы под-агентов — в виде локального Markdown + JSON. Успешные экспорты сохраняют необработанные ответы API вместе с отрисованными артефактами, поэтому рендеринг можно повторно запускать в автономном режиме в любое время.

<a id="introduction" data-pplx-source-anchor="true"></a>
## Введение

Помимо архивирования исторических разговоров, этот проект в первую очередь направлен на то, чтобы предоставить локальным агентам — находящимся ближе к данным и часто поддерживаемым большими вычислительными мощностями — некоторую часть возможностей Perplexity Computer. Предоставляя им доступ к отчетам, созданным Perplexity Deep Research, непосредственно в их рабочем цикле, они могут использовать высококачественную информацию для более точной настройки ключевых параметров в коде, более полно используя существующую подписку Perplexity Max.

> По состоянию на 20 июля Perplexity не предлагал официальный CLI для Unix-подобных сред. 23 июля Perplexity публично выпустил инструмент `pplx`, используемый в компьютерном режиме, но этот инструмент по-прежнему использует оплату по мере использования.

Это не полная замена компьютерного режима. Две возможности остаются недоступными:

- свобода навыка Deep Research выбирать произвольную модель;
- способность навыка Council запускать глубокое исследование с несколькими указанными пользователем моделями, создавать отчеты и сравнивать их бок о бок.

Каталог [`_platform_context/`](https://github.com/Yiksing/pplx-tools/tree/main/_platform_context)
содержит архивные системные подсказки и правила работы, которые могут помочь приблизить части рабочего процесса Computer локально, включая выбор режима Deep Research и выбор модели под-агента.

<a id="features" data-pplx-source-anchor="true"></a>
## Возможности

<a id="pplx-export-archive-your-library" data-pplx-source-anchor="true"></a>
### `pplx-export` — архивируйте свою библиотеку

- Индекс библиотеки и индекс пространства
- Однопоточный / пакетный экспорт с инкрементальной ранней остановкой и возобновляемыми контрольными точками
- Дозаполнение ресурсов и дозаполнение использования кредитов
- Граф связей разговоров
- Офлайн-перерендеринг (`re-render`, без сети)
- Фрагмент cron для периодического инкрементального обновления

<a id="pplx-ask-query-perplexity-from-the-shell" data-pplx-source-anchor="true"></a>
### `pplx-ask` — запрашивайте Perplexity из оболочки

- Потоковые запросы SSE в четырех режимах: поиск / глубокое исследование / совет / изучение
- Автоматическое перемещение в пространство BOT по завершении, уведомления о прочтении
- Автоматическое архивирование каждого созданного потока — создано так, чтобы другие агенты могли вызывать его для получения информации в реальном времени

Границы артефактов по режимам (цитаты / отчеты / ресурсы / под-агенты): см. [Режимы](guide/modes.md); принципы точности рендеринга: см. [Конвейер экспорта](architecture/export-pipeline.md).
